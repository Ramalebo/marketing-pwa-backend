# User Testing Guide - Simple Steps

## 🎯 What to Test (From User's Perspective)

Test your app like a regular user would - no technical knowledge needed!

---

## ✅ Step 1: Visit Your Website

1. **Open your browser**
2. **Go to**: `https://dominantlogic.tech`
3. **Check:**
   - ✅ Does the website load?
   - ✅ Does it look correct?
   - ✅ Can you see the homepage?

---

## ✅ Step 2: Test Registration

1. **Click** "Register" or "Sign Up" button
2. **Fill in the form:**
   - **Name**: `John Doe`
   - **Email**: `john@example.com`
   - **Password**: `Password123!`
3. **Click** "Register" or "Sign Up"
4. **What should happen:**
   - ✅ Success message appears
   - ✅ You're redirected to login page or dashboard
   - ✅ No error messages

**If it works:** ✅ Registration is working!

**If it doesn't work:** ❌ You'll see an error message - note what it says

---

## ✅ Step 3: Test Login

1. **Click** "Login" or "Sign In" button
2. **Enter your credentials:**
   - **Email**: `john@example.com` (the one you just registered)
   - **Password**: `Password123!`
3. **Click** "Login" or "Sign In"
4. **What should happen:**
   - ✅ You're logged in
   - ✅ You see the dashboard or home page
   - ✅ You stay logged in (don't get kicked out)

**If it works:** ✅ Login is working!

**If it doesn't work:** ❌ You'll see an error message - note what it says

---

## ✅ Step 4: Test Navigation

1. **After logging in**, try clicking different menu items:
   - Dashboard
   - Clients
   - Ads
   - Settings
   - Any other pages
2. **What should happen:**
   - ✅ Pages load correctly
   - ✅ No "404 Not Found" errors
   - ✅ Navigation works smoothly

**If it works:** ✅ Navigation is working!

---

## ✅ Step 5: Test Creating a Client (If Available)

1. **Go to** "Clients" page
2. **Click** "Add Client" or "New Client"
3. **Fill in client information:**
   - Name
   - Email
   - Phone
   - Any other fields
4. **Click** "Save" or "Create"
5. **What should happen:**
   - ✅ Client is created
   - ✅ Client appears in the list
   - ✅ Success message appears

**If it works:** ✅ Client creation is working!

---

## ✅ Step 6: Test Logout

1. **Click** "Logout" button (usually in top right or menu)
2. **What should happen:**
   - ✅ You're logged out
   - ✅ You're redirected to login page
   - ✅ You can't access protected pages anymore

**If it works:** ✅ Logout is working!

---

## ✅ Step 7: Test Login Again

1. **After logging out**, try logging in again with the same credentials
2. **What should happen:**
   - ✅ Login works
   - ✅ You can access your account again

**If it works:** ✅ Everything is working!

---

## 📋 Quick Test Checklist

**Test these basic functions:**

- [ ] Website loads
- [ ] Can register a new user
- [ ] Can login with registered user
- [ ] Can navigate between pages
- [ ] Can create/view data (clients, ads, etc.)
- [ ] Can logout
- [ ] Can login again after logout

---

## ❌ Common Issues You Might See

### "Error: Email already exists"
- **Meaning**: You're trying to register with an email that's already used
- **Fix**: Use a different email address

### "Error: Invalid email or password"
- **Meaning**: Wrong email or password
- **Fix**: Check your email and password are correct

### "Error: Network error" or "Failed to connect"
- **Meaning**: Can't reach the server
- **Fix**: Check your internet connection, or the backend might be sleeping (free tier)

### "Error: Something went wrong"
- **Meaning**: General error
- **Fix**: Try again, or check if the backend is running

### Page shows "404 Not Found"
- **Meaning**: Page doesn't exist
- **Fix**: Check if you're logged in, or the page might not be set up yet
