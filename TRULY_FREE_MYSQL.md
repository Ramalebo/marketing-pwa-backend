## 🥇 Option 1: FreeSQLDatabase.com (100% FREE)

**Completely free, no credit card, no trial period!**

### Step 1: Sign Up

1. **Go to** https://www.freesqldatabase.com
2. **Click** "Sign Up" (top right)
3. **Fill in**:
   - Username
   - Email
   - Password
4. **Click** "Create Account"
5. **Verify** email (check your inbox)

### Step 2: Create Database

1. **After logging in**, you'll see dashboard
2. **Click** "Create Database" or "New Database"
3. **Fill in**:
   - Database name: `marketing_pwa`
   - Choose region
4. **Click** "Create"

### Step 3: Get Connection Details

**After creating, you'll see:**
- Hostname (e.g., `sql12.freesqldatabase.com`)
- Port: `3306`
- Database name
- Username
- Password

**Copy these!**

### Step 4: Update Render

**In Render → Environment:**

```
DB_HOST = (hostname from FreeSQLDatabase)
DB_PORT = 3306
DB_NAME = (database name)
DB_USER = (username)
DB_PASSWORD = (password)
```

### Step 5: Import Schema

1. **In FreeSQLDatabase**, go to "SQL" or "Query" tab
2. **Paste** your schema from `backend/database/schema-no-database.sql`
3. **Run** it

**This is 100% FREE forever!** ✅
